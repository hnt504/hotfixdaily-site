Ways to cut the bill

  • Batch it. All three providers list Batch API prices at 50% off for work that doesn't need an instant reply.
  • Cache your long prefix. A cached system prompt or document is billed at a fraction of the input price on all three (see each source page for the exact rate).
  • Route by step. Send classification and simple tool calls to a small model and keep the big one for planning and hard debugging.
  • Cap output. Output tokens cost about 5 times more than input on most of these models (up to about 8 times on some), and reasoning tokens count as output.

FAQ

How is an AI API call priced?

By tokens. Providers charge one rate per million input tokens (your prompt, system prompt, tool definitions and history) and a higher rate per million output tokens (the reply, including reasoning or thinking tokens). Cost per request = input tokens x input price / 1,000,000 + output tokens x output price / 1,000,000.

Why might my real bill differ from this calculator?

This uses standard list prices only. Batch processing is 50% cheaper at OpenAI, Anthropic and Google; prompt caching makes repeated input much cheaper; some models charge more above a prompt-length threshold; and OpenAI charges 10% more on regional data-residency endpoints for newer models. Tokenizers also differ: Anthropic says Claude 4.7 and later models produce about 30% more tokens for the same text.
