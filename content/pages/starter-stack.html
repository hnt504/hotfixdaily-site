The 5 rules

  1. Write the rules once. Put build, test and style commands in AGENTS.md (or CLAUDE.md) so every agent follows them. Source
  2. Checkpoint before every task. Commit before and after each agent task so any change can be undone. Source
  3. No proof, no merge. The agent runs tests or the build and shows the output before it says "done". Source
  4. Fresh eyes on every diff. Have a second, fresh-context session review the change. Source
  5. Secrets stay secret. Keep API keys out of front-end code and chat prompts; use environment variables.
