AI deprecation deadlines for builders

Model IDs don't last. Between now and the end of 2026, OpenAI, Anthropic, Google, GitHub Copilot and Azure OpenAI are switching off more than 30 models and three whole products, and when the date passes, requests to a retired model fail. This page lists every upcoming shutdown we could confirm on each vendor's own deprecation page, with the date, what to switch to and the link. Every row was checked on October 27, 2026. Bookmark it, then search your code for the IDs below.

OpenAI: Evals, Agent Builder, prompts, images and GPT-5

OpenAI has the busiest November. Three products, not just models, go away on November 30, 2026:

  • Evals platform. Existing evals turn read-only on October 31, and the Evals dashboard and API shut down on November 30. Graders used in eval workflows are part of the change. OpenAI points to its "Moving from OpenAI Evals to Promptfoo" guide.
  • Agent Builder. Shuts down November 30. ChatKit stays. OpenAI's migration guide moves you to the Agents SDK or ChatGPT Workspace Agents.
  • Reusable prompts. The v1/prompts API and prompt objects shut down November 30. Copy each prompt's text into your code before then.

Then two model batches: older GPT Image models (gpt-image-1-mini, gpt-image-1.5, chatgpt-image-latest) on December 1, and the original GPT-5 family plus o3 on December 11. For gpt-5-pro and o3-pro, OpenAI's replacement is gpt-5.6-sol with reasoning.mode: pro.

OpenAI also gives a way to check from code: the List models endpoint (GET /v1/models) returns a shutdown_date for each model, or null if none is announced. Preview models (anything with "preview" in the name) can be retired with as little as two weeks' notice, so don't build on them for production.

Source: OpenAI deprecations (checked Oct 27, 2026)

Anthropic: Claude Sonnet 4.5 on November 30

Anthropic deprecated claude-sonnet-4-5-20250929 on September 30, 2026, and retires it on the Claude API on November 30, 2026. After that, requests fail. The recommended replacement is claude-sonnet-5-5.

The date covers Anthropic-operated platforms: the Claude API, Claude Platform on AWS, Claude Models on Google Cloud (Anthropic managed) and Microsoft Foundry. Amazon Bedrock and Google-managed Claude on Vertex AI set their own schedules, so check those consoles if you use them.

No other Claude model has a retirement date in 2026 on Anthropic's page. Two are worth watching: Claude Opus 4.5 is listed as Active with a retirement "not sooner than November 24, 2026," and Claude Haiku 4.5 "not sooner than October 15, 2026." Anthropic promises at least 60 days' notice, so neither should retire before late December 2026. Anthropic also removed temperature, top_p and top_k in API version 2026-10-21; they return a 400 error there.

Source: Anthropic model deprecations (checked Oct 27, 2026)

Google Gemini API: preview audio and TTS on November 17

Five preview models in the Gemini API have a shutdown date of November 17, 2026. All are audio:

  • Text-to-speech: gemini-2.5-flash-preview-tts, gemini-2.5-pro-preview-tts and gemini-3.1-flash-tts-preview. Switch to gemini-3.8-flash-tts or gemini-3.8-flash-lite-tts.
  • Live API: gemini-3.1-flash-live-preview and gemini-2.5-flash-native-audio-preview-12-2025. Switch to gemini-3.8-live.

Google says its dates are the earliest possible shutdown and that it will confirm exact dates with notice. Plan for November 17 anyway. Two more things on the same page: gemini-3.7-flash and gemini-3.5-flash aren't shutting down but now route requests to newer Flash models, and access to the 2.5 models is limited to people who already used them.

Source: Gemini API deprecations (checked Oct 27, 2026)

GitHub Copilot: three models leave on November 16

GitHub's October 15 changelog says it will remove these models from every Copilot experience (Chat, inline edits, ask and agent modes, code completions) on November 16, 2026:

  • Claude Opus 4.8 and Claude Opus 5: switch to Claude Opus 5.5. Opus 4.8 stays for individual subscribers on annual plans.
  • GPT-5.6 Terra: switch to GPT-6.1 Sol or GPT-6 Luna.

For Copilot Business and Enterprise, the alternatives are turned on automatically unless an admin turned off the global default or disabled the model. If you pin a model in a Copilot CLI script, custom agent or team policy, update it. You don't need to remove the old models; they disappear on their own. This is Copilot only: the same models remain on Anthropic's and OpenAI's own APIs.

Source: GitHub changelog, Oct 15, 2026 · Copilot model retirement history (checked Oct 27, 2026)

Azure OpenAI and Microsoft Foundry

Azure runs its own retirement dates, separate from OpenAI's. Before the end of 2026, Microsoft's schedule lists codex-mini (November 15), the o-series reasoning models o1, o1-pro, o3, o3-pro, o3-deep-research, o3-mini and o4-mini (November 19), gpt-4o version 2024-05-13 (December 9), whisper, tts and tts-hd (December 15) and gpt-image-1.5 (December 16).

The same schedule lists Claude on Foundry: claude-sonnet-4-5 on November 30 (replacement claude-sonnet-5-5), and also claude-haiku-4-5 on November 15 and claude-opus-4-5 on November 24. Anthropic's own page still shows Haiku 4.5 and Opus 4.5 as Active, so if you run them on Foundry, check your deployment's retirement date in the Foundry portal and assume the earlier one.

Source: Foundry model retirement schedule (checked Oct 27, 2026)

How to find what you're using

  • Search the code. Run git grep -n -E "sonnet-4-5|gpt-5-mini|gpt-image-1|o4-mini|preview-tts|native-audio-preview" and extend the pattern with IDs from the tables. Check .env files, CI secrets and agent config too.
  • OpenAI: GET /v1/models returns a shutdown_date per model.
  • Anthropic: Claude Console, Usage page, Export. The CSV breaks usage down by API key and model.
  • Aliases: an alias like gpt-5 points to a dated snapshot (gpt-5-2025-08-07), and both retire together.
  • Fine-tunes: OpenAI fine-tuned models follow their base model's shutdown date.

Our take: put the model ID in one config value, not scattered across files, and run your test suite against the replacement a week before the deadline. Replacements are rarely drop-in: output length, tool-call formats and supported parameters change.

The 15-minute checklist

  • Grep every repo for the model IDs above.
  • Export OpenAI Evals data before October 31 (read-only after) and November 30 (gone).
  • Move Agent Builder flows and reusable prompts into code before November 30.
  • Switch Claude Sonnet 4.5 to claude-sonnet-5-5 and rerun your evals.
  • Swap Gemini preview TTS and Live models before November 17.
  • Update pinned Copilot models in scripts and team policies before November 16.
  • Check Azure deployments separately; their dates differ from OpenAI's.
  • Set a calendar reminder two weeks before each date that applies to you.

FAQ

When does Claude Sonnet 4.5 retire?

Anthropic retires claude-sonnet-4-5-20250929 on the Claude API on November 30, 2026, and requests to it fail after that date. The recommended replacement is claude-sonnet-5-5. Microsoft Foundry's schedule lists the same date. Amazon Bedrock and Google-managed Vertex AI set their own dates, so check those separately. Checked Oct 27, 2026.

What happens when OpenAI Evals shuts down?

OpenAI's deprecations page says existing evals become read-only on October 31, 2026, and the Evals dashboard and API shut down on November 30, 2026. Graders used in eval workflows are part of the change. OpenAI's suggested path is its guide to moving from OpenAI Evals to Promptfoo. Export your eval data before November 30.

Which Gemini models shut down on November 17, 2026?

Google's Gemini API deprecations page lists five preview models for November 17, 2026: gemini-2.5-flash-preview-tts, gemini-2.5-pro-preview-tts and gemini-3.1-flash-tts-preview (replace with gemini-3.8-flash-tts or gemini-3.8-flash-lite-tts), plus gemini-3.1-flash-live-preview and gemini-2.5-flash-native-audio-preview-12-2025 (replace with gemini-3.8-live). Google calls these the earliest possible shutdown dates.

Which models is GitHub Copilot removing on November 16, 2026?

GitHub's October 15 changelog says Claude Opus 4.8, Claude Opus 5 and GPT-5.6 Terra leave all Copilot experiences on November 16, 2026. GitHub suggests Claude Opus 5.5 for both Opus models and GPT-6.1 Sol or GPT-6 Luna for Terra. Opus 4.8 stays for individual subscribers on annual plans. This only affects Copilot; the same models stay available on Anthropic's and OpenAI's own APIs.

How do I find out if my app uses a deprecated model?

Search your code and config for the model IDs in the table. On OpenAI, call GET /v1/models and check each model's shutdown_date field. On Anthropic, export usage from the Claude Console Usage page to see usage by API key and model. Also check environment variables, agent config files and any SDK defaults that pin a model.

What we left out: we list only dates we found on the vendor's own deprecation page or changelog on October 27, 2026. Models already retired, models with no shutdown date, and Amazon Bedrock and Vertex AI schedules for Claude aren't covered. Vendors change these pages often, so check the linked page before you rely on a date.
