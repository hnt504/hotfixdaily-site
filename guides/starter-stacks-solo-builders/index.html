Stack 1: The no-code founder

Our take: stay in one browser app until real users ask for something it can't do. First thing to pay for: more Lovable credits, once you run out of the daily grant every day. When to graduate: when you need code review, tests or a feature the builder fights you on, sync to GitHub and move to Stack 2. The steps are in our vibe coding workflow.

Build and host: Lovable

Free option · entry price: Free: 5 build credits a day (up to 30 a month) + 20 Cloud credits a month

Lovable says hosting most small or new apps is covered by the grant that comes with your plan; apps with significant traffic or size draw on your credit balance. You own the code and apps you build.

Our take: Alternatives (Bolt, v0, Replit and more) are in our vibe coding tools guide.

Source

Payments: Stripe

Free option · entry price: No monthly fee · 2.9% + 30¢ per successful domestic card charge

Stripe lists no setup, monthly or closure fees on standard pricing. International cards and other payment methods are priced differently.

Source

Email list: Kit (affiliate)

Free option · entry price: Free up to 10,000 subscribers · Creator $33/month (at 1,000 subscribers)

The Free plan includes unlimited landing pages, forms and broadcasts. Creator adds visual automations and email sequences.

Our take: Start on Free; pay when you want an automated welcome sequence.

Source (affiliate)

Stack 2: The TypeScript web SaaS

Our take: the default for a solo dev who can read code. Every layer has a usable free tier, and Supabase and Stripe have official MCP servers, so your agent can work on the backend too. First thing to pay for: Vercel Pro the day you take money, because Hobby is non-commercial.

Coding agent: Claude Code or GitHub Copilot

Free option · entry price: Copilot Free (CLI and agent mode, limited) · Copilot Pro $10 · Claude Pro $20 ($17 billed annually)

Claude Code comes with Claude Pro and Max, not the Free plan. Copilot's Free plan supports the CLI and agent mode with limited usage.

Our take: Compare all of them in which AI coding agent and AI coding agents.

Copilot plans · Claude pricing

Framework: Next.js + AI SDK

Free option · entry price: Free, open source (Next.js: MIT; AI SDK: Apache-2.0)

Next.js for the app, and Vercel's AI SDK for chat and tool-calling features.

Our take: Mastra is the pick if you want workflows and memory built in; see AI agent frameworks.

Next.js · AI SDK

Database and auth: Supabase

Free option · entry price: Free: 500 MB database, 50,000 monthly active users, 2 active projects · Pro from $25

Free projects pause after 1 week of inactivity. Pro includes $10/month in compute credits, which covers one Micro project, and has spend caps on by default.

Source

Hosting: Vercel

Free option · entry price: Hobby $0 (personal, non-commercial use) · Pro $20 per developer seat

Vercel says Hobby is for personal, non-commercial use and Pro is for professionals and businesses. New teams get spend management with a default on-demand budget.

Our take: Charging customers? Plan on Pro.

Source

Payments and email: Stripe and Kit

Free option · entry price: Stripe 2.9% + 30¢ per domestic card charge · Kit free to 10,000 subscribers

Same picks as Stack 1. See Kit's pricing (affiliate) for paid plans.

Stripe pricing · Kit pricing (affiliate)

MCP servers to connect

Free option · entry price: Supabase MCP · Stripe MCP · Playwright MCP

Supabase MCP has a read-only option. Stripe MCP lets you grant access to live mode or a sandbox separately. Playwright MCP lets the agent click through your app in a browser.

Our take: Use Supabase read-only on production and connect Stripe to a sandbox first. More in MCP servers worth knowing.

Supabase MCP · Stripe MCP · Playwright MCP

Stack 3: The Python AI app

Our take: for when the AI is the product (a research bot, an internal agent, an API). Keep the framework small and the model swappable. First thing to pay for: model usage. Put a budget cap on your OpenRouter or provider key before you share the app.

Coding agent: Codex or Claude Code

Free option · entry price: Codex in ChatGPT Free for quick tasks · CLI and IDE extension from Plus ($20) · or an API key at API rates

OpenAI lists Codex in ChatGPT Free for quick coding tasks in the desktop app (subject to rollout). Codex on the web, in the CLI and in the IDE extension starts with Plus. With an API key you pay API rates, which OpenAI suggests for automation like CI. Claude Code needs Claude Pro or Max.

Codex pricing · Claude pricing

Agent framework: Pydantic AI

Free option · entry price: Free, open source (MIT)

Type-checked inputs and outputs and testable agents. Prefer a vendor SDK? The OpenAI Agents SDK is MIT too.

Our take: The full comparison is in AI agent frameworks.

Pydantic AI · OpenAI Agents SDK

API: FastAPI + uv

Free option · entry price: Free, open source (FastAPI: MIT; uv: MIT or Apache-2.0)

FastAPI for the API, and uv to manage Python versions and dependencies.

FastAPI · uv

Models: OpenRouter or Ollama

Free option · entry price: OpenRouter Free: 25+ free models, 50 requests/day · pay-as-you-go: 5.5% fee on credit purchases · Ollama: free locally

OpenRouter gives you one API across providers and bills models at the provider's list price; budgets and spend controls come with pay-as-you-go. For local development, Ollama runs models on your machine for free (MIT-licensed); its paid plans, from $20/month, add usage credits for its cloud models.

OpenRouter pricing · Ollama pricing · Ollama license

Hosting: Render

Free option · entry price: Free web service (512 MB RAM, usage limits) · paid instances from $7/month

Render's Hobby workspace is $0 plus compute. Free compute plans have usage limits and are meant for personal projects and prototypes. Managed Postgres has a free tier too.

Source

Stack 4: The indie game dev

Our take: use the coding agent you already pay for and connect it to the engine. Buy asset tools only when placeholders start slowing you down. First thing to pay for: a coding agent plan, if you don't have one. Asset tools come second. More engine agents (Unreal, Roblox) and asset tools are in our AI game dev tools guide.

Engine, option A: Unity Personal + your coding agent

Free option · entry price: Unity Personal: free up to $200,000 in revenue and funding · CLI, MCP server and plugin free (Unity 6+)

Unity offers an official plugin for Claude Code, Codex and Grok, plus a Unity CLI with an MCP server. Unity's FAQ says all three are free with no concurrency limits. Only the in-editor assistant costs extra: on Personal, its free trial converts to $10/month.

Unity AI FAQ · Unity plans

Engine, option B: Godot

Free option · entry price: Free and open source (MIT)

Godot's license terms don't apply to the games you make, so you can license them however you like.

Our take: Its scripts and scenes are plain text files, which coding agents handle well, but there's no official AI plugin like Unity's, so you wire up the agent yourself.

Source

3D assets: Meshy

Free option · entry price: Free: 100 credits a month · Pro $20/month billed monthly (1,000 credits)

Free-plan assets are licensed CC BY 4.0, so commercial use is allowed with attribution to Meshy. On paid plans you own the assets you create.

Source

Voice and sound: ElevenLabs

Free option · entry price: Free: 10,000 credits a month · Starter $6/month (30,000 credits, commercial license)

The commercial license starts on the Starter plan. All products (text to speech, sound effects, music) draw from one shared credit pool.

Source

Ship it: itch.io

Free option · entry price: Free to publish · you set the revenue share (default 10%)

itch.io says it costs nothing to use and never places ads on your pages. You choose what share of sales goes to itch.io; the default is 10%, and payment processor fees come out separately.

itch.io FAQ · Payments docs

Rules for every stack (our take)

  1. One agent, one instructions file. Put build, test and style commands in AGENTS.md so you can switch agents later. See the Starter Stack rules.
  2. No proof, no merge. The agent shows passing tests, a clean build or a screenshot before you accept "done".
  3. Secrets stay out of the front end. API keys go in environment variables, never in client code or prompts.
  4. Cap your spend. Supabase Pro has spend caps on by default, and Vercel and OpenRouter (pay-as-you-go) have budget controls. Turn them on before launch.
  5. Upgrade one layer at a time, and only when you hit a limit every week.

FAQ

What's the cheapest stack to start with?

All four can start at $0. The cheapest paid coding agent in this guide is GitHub Copilot Pro at $10/month. Our take: spend your first dollars on the coding agent, not on hosting.

Can I use the TypeScript stack for a commercial app on free tiers?

Not on Vercel's free plan: Vercel says Hobby is for personal, non-commercial use, so move to Pro ($20/month) before you charge customers. Also note that Supabase Free projects pause after a week of inactivity.

Which stack should a non-coder pick?

Stack 1. When you outgrow the browser builder, sync to GitHub and move to Stack 2. Our vibe coding workflow covers the handoff.

Do I need an agent framework for a simple AI feature?

Usually not. In a web app, the AI SDK is enough for chat and tool calls. Our take: reach for a framework when the agent itself is the product. See AI agent frameworks.

Can I sell a game made with free Meshy and ElevenLabs plans?

Meshy's Free plan allows commercial use with attribution (CC BY 4.0). ElevenLabs lists its commercial license from the $6 Starter plan, not on Free.
